## 2. 当前产品真值

- ADR-0022 是最高产品范围：目标是类别开放的通用参考条件 3D Agent；ADR-0023 固定 DeepSeek/千问唯一 AI Provider；当前 Alpha 仍主要执行机械臂/机械硬表面；
- 当前主链为 `千问视觉证据 → SubjectProfile → VisualFeatureContract → RepresentationPlan → DeepSeek typed program → UniversalAssetSource → 本地 GLB/PBR`；U002/U003 已实现理解、规划和当前程序化 source。旧实验 Mesh Seed 路线已从运行时移除，不能被写成 universal capability；
- Rust app-server/core 单一拥有 Agent、Provider、Project/Version、`ActiveDesignSnapshot`、ChangeSet、Quality、Export、SQLite/WAL 和 CAS；Python 只执行受限几何；
- 工作台只展示一个结果并复用一个 Three.js renderer；永久修改统一 preview→confirm→不可变子版本；
- 当前机械臂工程闭环可运行，但参考相似度和独立真人 `4/5` 未通过；本机开发作者已新增 `procedural.generic_visual_exterior_v1`，可为车辆、家具、建筑、植物、动物、角色、机械设备、虚构游戏道具和未知对象生成轻量外观代理；它不等于照片级重建，Hybrid 仍仅指受限的本地硬表面逐部件组合，不得写成通用混合重建；
- `procedural.generic_visual_exterior_v1` 现在由 Rust 直接视为类别开放的可见外观代理，不再要求 DeepSeek 自报 `visual_exterior` 标签；animal/quadruped、植物、建筑等 SubjectProfile 可在保留自身身份标签的同时进入该路径。该修复只消除错误的 author 准入拒绝，复杂有机对象仍是 proxy/可能受限，不能写成专用 deformable、neural 或照片级能力；
- Weapon/Concept 只读与回归事实统一见 `COMPATIBILITY_MIGRATION.md`，旧独立操作文档已删除。
