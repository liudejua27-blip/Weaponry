# Knife reference convergence loop

Read this before the first Dragonfang geometry write and after every failed High review. The full
authority is `docs/WEAPONRY_KNIFE_REFERENCE_CONVERGENCE_DESIGN_20260830.md`.

## Required order

1. Read the eligible immutable Brief and exact reference hashes.
2. Create or read the Runtime-owned `KnifeReferenceIntentBundle`: intake, detail inventory and
   quality contract. Preserve hidden regions as `unknown/inferred`.
3. Execute only the unlocked pass:
   `camera-lock → silhouette-blockout → structural-form → secondary-form → high-geometry`.
4. Run geometry/readback hard gates before render.
5. Review one exact fixed reference view plus at least two non-degenerate orbit views using the
   same candidate, scene, camera set and cohort.
6. Choose exactly one decision: `continue`, `refine-spec`, `refine-code`, `request-input`, `stop`.
7. Change one bounded scope, create a separate attempt, and preserve the baseline.
8. Observe/read back after every write. Never confirm or unlock Low from a structural-only result.

## Dragonfang correction priority

`camera → silhouette → primary proportion → secondary form/negative space → cross-section/topology → identity detail → material → lighting`

An earlier failure blocks later compensation. A projected dragon pattern cannot replace blade
relief; a bright edge cannot replace grind/bevel geometry; material and lighting cannot repair a
flat blade or wrong guard silhouette.

## Stop conditions

- Three attempts in one pass or six in Slice A without a passing successor;
- the same defect repeats twice without meaningful improvement;
- the correction oscillates between previous states;
- a missing top/bottom/front-three-quarter/FPS-inspect view is required to decide;
- binding, topology, readback, cohort or budget integrity fails.

Stop as `request-input` or `blocked`, retain all attempts, and name the missing evidence. A single
reference sheet supports visible-view High work but never `HQ_360_PASS` or commercial acceptance.
