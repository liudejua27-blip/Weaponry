WPN-THREE-EVAL-001 report

Scope
-----
Added a closed typed fixed-view data plane under packages/weaponry-threejs.
The canonical KnifeFixedEightViewRig@1 contains exactly these ordered views:

  FRONT, BACK, TOP, BOTTOM, LEFT, RIGHT, REAR_THREE_QUARTER, FPS_HOLD

Each view has a deterministic camera descriptor. The first seven use a fixed
orthographic projection and FPS_HOLD uses a fixed perspective projection. The
CPU helper remains renderer-independent; the sibling browser route now invokes
THREE.WebGLRenderer with the same fixed rig and records the live camera matrices.

Projection and mask API
-----------------------
- createKnifeViewRig / createKnifeViewCamera
- projectKnifeScene
- rasterizeKnifeMask (also exported as generateKnifeMask)
- evaluateKnifeView / evaluateKnifeRig

Projection produces deterministic pixel coordinates, NDC depth, clip visibility,
stable part/material indexes, and a WeaponryThreeJsProjectionReceipt@1.
Mask generation is a bounded CPU triangle rasterizer with depth ordering and no
anti-aliasing. It produces binary pixels, part/material index buffers, depth,
and a WeaponryThreeJsMaskReceipt@1. Per-view and eight-view structural receipts
keep renderer_invoked=false and quality_status=NOT_RUN.
